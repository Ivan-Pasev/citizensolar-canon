## Source Discipline

Every public claim should be classified as:

| Class | Meaning |
|---|---|
| `SOURCE-LIVE` | Derived from citizen.solar public pages |
| `SOURCE-OFFICIAL` | Government, regulator, standards body, IRS/DOE/EU etc. |
| `SOURCE-MARKET` | Market research, analyst, industry source |
| `SOURCE-INFERENCE` | Strategic synthesis from multiple sources |
| `SOURCE-INTERNAL` | Internal working doctrine, not external evidence |

## Refresh Rule

Refresh before investor release, funding submission, procurement discussion, or public route update.

Do not treat old market/regulatory claims as permanent. Mark old values as dated and replace with current evidence when new data exists.
